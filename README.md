# Norion International

Website for Norion Caritas Foundation, headquartered in Benin City, Edo State, Nigeria.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Available commands

- `npm run dev` starts the development server.
- `npm run build` creates a production build.
- `npm run start` serves the production build.
- `npm run lint` runs ESLint.
- `npm run typecheck` runs TypeScript checks.

## Media

Website images and video records are stored in `public/images` and `public/videos`. Original source media remains in the local `Norion videos` folder and is excluded from this public repository.

## Built with

Next.js, React, TypeScript, Tailwind CSS, and Framer Motion.
